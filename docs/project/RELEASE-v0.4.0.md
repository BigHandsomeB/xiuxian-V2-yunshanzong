# v0.4.0 · 山外探索与宗门旧事

运行方式：网页／服务器源码，需要 Python 后端与浏览器。Windows 独立桌面版继续使用自己的分支与 v0.3.0-windows 发行包，本次不替换桌面版。

## 新增内容

- 冒险探索与特殊事件：四处探索地点、十二项事件，使用真实服务器条件、消耗、时长与奖励。
- 主线记录：五章主线及独立筑基记事，共36个节点；支持待阅读、已阅读回看和显式标记。阅读不暂停挂机，也不额外赠送奖励。入口位于冒险顶部“战斗记录”之后。
- 万宝楼自动补货：多份材料保有量清单，弟子执行，共用每日行情与限购，支持离线逐日结算。
- 进入游戏默认到宗门，新增山门、云海、石阶与青玉云纹加载主视觉；首页图片有最长等待时间和加载失败重试。
- 功法阁换为与同组建筑一致的正式图标。设置新增离线战报自动弹出开关，默认开启并保存浏览器选择；四个工具按钮图标固定在左侧。
