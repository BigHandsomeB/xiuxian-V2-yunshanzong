# v0.3.0 发布说明（2026-10-18）

## main · 法宝与功法秒制冷却（2026-10-18）

- 五件法宝：斩妖飞剑、镇岳鼎、噬魂幡、寒魄印、赤焰葫。炼器阁集中炼制、装备、投喂升级和强化；需要对应Boss核心、大量材料与2至12小时炼制。
- 法宝装备后在主角左上方浮空，由程序驱动动作；炼器阁一行两张卡片，上方大图、下方名称和小字说明。
- 功法自动技能使用游戏时间冷却：身法10秒、防御12秒、绝技8秒、终极24秒；身法/防御运转6回合，50部内功保持原规则。旧战斗按已保存快照继续，新规则用于新战斗。
- 素材管理器新增法宝128×128类型，支持先批量导入名称、再按顺序或名称批量补外观方向；外观方向随提示词冻结保存。
- 新档直接加载当前内容；旧档先备份，通过两个显式升级工具迁移，保留装备、库存、世界时间、身份与旧战斗。见[升级步骤](UPGRADE-main-artifacts.md)。
- 手机实际绘制、触摸、长时挂机和高等级平衡继续验收；代码检查不等同于实机验收。
