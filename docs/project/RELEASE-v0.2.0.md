# v0.2.0 · 离火丹墟与功法流派更新

本次版本新增第五副本，更新前五副本装备属性和150部功法特殊机制，并接入完整的对应特效反馈。

## 新增与更新

- **离火丹墟**：100层、10只普通怪、5只精英与离火丹魔；12件装备、12种专属材料与4种主题材料。通关寒玉冰窟100层后解锁。
- **前五副本装备**：60件装备的属性方向和特色机制；新掉落采用新范围，已保存的旧装备不重抽属性。
- **150部功法**：数据化触发、状态、护盾、治疗、持续伤害、控制、资源、冷却与次数限制；绝技和终极按条件自动施放，八功法槽保留。
- **战斗特效**：13个新特效/42帧，复用8个旧特效，补齐灵气爆破播放；按真实元素和状态选择反馈，保持并发上限与后台暂停。
- **近期体验与工具**：功法槽原地装备/更换/卸下、设置页入口整理；素材工具改进特效分帧与发布后的原图清理。正式游戏只依赖批准Runtime，无需素材管理器常驻。

## 下载与存档

下载本页的 **Source code (zip)**，按[README](https://github.com/BigHandsomeB/xiuxian-V2-yunshanzong#本地运行)启动。首次运行`tools.playable.setup_local`创建当前完整内容的新档；已有存档不要再次初始化。

v0.1.0存档需先停止自己的游戏服务，再按[升级说明](https://github.com/BigHandsomeB/xiuxian-V2-yunshanzong/blob/v0.2.0/docs/project/UPGRADE-v0.2.0.md)备份并执行显式内容升级。升级保留旧装备、进度和原战斗；原战斗按旧快照继续，后续新战斗启用新机制。新版本产生内容后，回退必须恢复升级前完整备份。
