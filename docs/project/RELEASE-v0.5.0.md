# v0.5.0 · 逐格种养、装备精炼与配方派工

这是网页／服务器源码发行版，需要 Python 后端与浏览器。Windows 独立桌面版继续保留 v0.3.0-windows，本次不替换其发行包。

## 更新

- 灵植每株、灵兽每只、水产每尾统一占 1 格，全部 24 种养殖品种一致；原来占 2～3 格的品种释放其余格位。已有存栏保留数量、安置位置、生长进度与自动续养设置。
- 灵植园逐格开垦、种植和自动续种；仙石兽栏与青玉灵池五列格子安置，成熟后自动采集，并按原费用续养。缺材料、照料弟子或仓容时按原规则等待。
- 炼器阁增加装备精炼：1 个装备大格、3 个矿石／怪物材料格，84 种材料按来源和特性提供属性贡献，显示加成预览与精炼装备光晕。
- 弟子居先显示各建筑人数，再进入配方行，用右侧加减按钮每次调整 1 人。不同配方独立安排；本轮忙碌弟子减员后等待批次结束释放。同一建筑仍按原单批次轮换生产。
- 同步当前已实现的定向属性试炼场及相关界面改进。旧战斗缺装备快照时增加不可能组合剪枝，保持校验规则，改善冷启动耗时。
