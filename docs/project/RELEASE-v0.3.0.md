# v0.3.0 · 法宝与功法秒制冷却

本次版本加入五件可炼制法宝、正式法宝外观、法宝培养，以及功法自动技能的秒制冷却。

## 新增与更新

- **五件法宝**：斩妖飞剑、镇岳鼎、噬魂幡、寒魄印、赤焰葫；用对应Boss核心、大量材料和2至12小时炼制，在炼器阁集中管理。
- **法宝培养**：独立装备槽、投喂怪物材料升级、随击杀获得经验及强化。战斗开始冻结法宝快照，在线和离线沿用同一奖励结算。
- **正式外观**：五张128×128透明素材，法宝在主角左上方浮空，由程序驱动动作；法宝页一行两张大图卡片，图片下方显示小字说明。
- **功法秒制冷却**：身法10秒、防御12秒、绝技8秒、终极24秒；身法/防御运转6回合，50部内功保持原规则。当前旧战斗继续使用原快照，新规则用于新开的战斗。
- **素材管理器**：法宝专用128×128类型，支持先批量导入名称，再按顺序或名称批量补充外观方向；提示词保留冻结的逐件方向。
- **扩展接口**：法宝定义、Boss材料来源、配方、成长、效果和程序动作集中登记，便于后续副本接入。
